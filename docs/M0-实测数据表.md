# M0 实测数据表（K90 至尊 / HyperOS 4 / Android 17）

> 目的：在接真模型前，先把"通话链路"和"OCR 链路"的基础开销钉死。
> 所有数字必须来自**真机**，模拟器数据不作数。

## 1. 采集方式

```bash
# 清空并实时抓性能打点（另开一个终端）
adb logcat -c
adb logcat -s WOILAI_PERF

# 会话结束采一次内存与温度
adb shell dumpsys meminfo io.github.wumisc.woilaibangni | head -20
adb shell dumpsys thermalservice | head -30
adb shell dumpsys battery | grep -E "level|temperature"
```

App 内已埋点：
- `first_partial_ms`：VAD 判定开始说话 → 第一个字上屏
- `finalize_ms`：VAD 判定说完 → 定稿回填
